# 更新公告维护说明

更新公告配置位于 `app/src/main/java/com/grasscutter/m/MainActivity.kt` 的 `currentAnnouncement`。

发布下一次更新时：

1. 修改 `id`。每个公告必须使用新的编号，例如 `7.0.1`，这样已经选择“不再显示”旧公告的用户仍能看到新公告。
2. 修改 `version`、`title`、`body` 和 `explanation`。
3. 将 `quarkUrl` 或 `pan123Url` 替换为真实下载地址。链接为空时，应用只显示“链接待填写”，不会生成错误跳转。
4. 提交并构建 APK 后，再将公告分支合并到发布分支。

弹窗有两种关闭方式：

- `关闭本次公告`：只关闭当前打开的弹窗；下次进入应用仍会显示。
- `本次不再显示`：记录当前公告编号；该编号以后不再显示。下一次修改 `id` 后，新公告会再次显示。
